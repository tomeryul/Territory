# Avatars — תמונות דמויות

כאן שמים תמונות של דמויות לאווטאר השחקן.

## פורמט מומלץ
- **PNG עם רקע שקוף** (כדי שלא יהיה ריבוע סביב הדמות).
- ריבועי (1:1) — נראה הכי טוב באווטאר.
- פיקסל-ארט מתאים מצוין לסגנון המשחק.

## אנימציה (כמה פוזות)
שמים פריים לכל פוזה, ממוספרים לפי הסדר, למשל:
```
assets/avatars/hero_1.png
assets/avatars/hero_2.png
assets/avatars/hero_3.png
```
ואז מוסיפים רשומה אחת ב-`src/core/avatars.js`:
```js
{ id:'hero', name:'גיבור',
  frames:['assets/avatars/hero_1.png','assets/avatars/hero_2.png','assets/avatars/hero_3.png'],
  fps:5 }
```
זהו — הדמות תופיע בבורר האווטארים במסך הפרופיל ותונפש אוטומטית.

## ללא קבצים?
אפשר גם פשוט להעלות תמונה אחת מתוך האפליקציה (פרופיל → "העלה אווטאר").
